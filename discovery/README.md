# Discovery

What we learn about the people Together is for: couples planning a wedding and the parents
helping them.

- `interviews/`: one file per conversation, anonymized ("bride, Provo" or "mother of the
  groom, Salt Lake", never a name, email, or phone number)
- `personas.md`: one entry per kind of user, getting more specific over time
- `insights.md`: numbered findings that hold across conversations, each linked to its sources
