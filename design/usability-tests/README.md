# Usability tests

One file per session, named `NNN-short-description.md` (for example
`001-couple-guest-list.md`). Each one covers:

- **Who:** anonymized (a couple, a parent, a helper; how they plan today)
- **What we asked them to do:** the tasks, in their words where possible
- **What they did:** where they went, where they hesitated or got stuck, what they skipped
- **What to change:** the fixes this session points to, ranked

Write down what they did, not just what they said about it.
